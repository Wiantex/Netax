Özellikler (kısa):
- yazdir: ekrana yazma (print)
- var / f: değişken tanımlama (var, f)
- eger: koşullu (if)
- iken: döngü (while benzeri)
- dongu: basit döngü yapısı
- kir / devam: kırma (break) / devam (continue)
- fonksiyon: fonksiyon tanımı
- dogru / yanlis: boolean literalleri
- ve / veya / degil: mantıksal işlemler
- liste: dinamik diziler
- ekle / sil / uzunluk: liste işlemleri (append/remove/length)
- Giris: program giriş noktası (entry)

Not: Keyword'ler büyük/küçük harf duyarsızdır (ör. Yazdir, yazDIR aynı).
