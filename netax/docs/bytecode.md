.bax dosya yapısı (kısa)

.bax = NATX başlığı + version + constants + code

Bu dosya formatı, derlenmiş Netax bytecode'unu saklamak için tasarlandı. Uzun bir spesifikasyon bu sürümde yer almıyor; temel bileşenler belirtilmiştir.

Short English: .bax files store NATX header, version, constants and bytecode.
